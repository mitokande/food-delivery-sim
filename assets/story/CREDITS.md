# Story art (Uncle's Diner)

All files here were generated on 2026-11-09 with OpenAI's image API (model `gpt-image-2.6-flare`, quality medium) by
`tools/genart.mjs`; the prompts are in that file.
- `letter`, `diner`, `scooter`, `smash`: the story cards.
- `stage2`…`stage5`: the restaurant's stages, each an edit of the one before (`diner` is stage 1), so it stays one building.
- `cook-btn`: the COOK button.
The webp copies were made by `tools/genart-webp.py`.
