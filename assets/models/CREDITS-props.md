# Street props kit (`props.glb`)

Everything in `props.glb` is original procedural geometry. It is generated by `tools/blender/props.py` (Blender 5.2, headless) from bmesh primitives (boxes, lathes, swept tubes, icospheres, polygons). No third-party meshes or textures are used, so there is nothing to attribute. The kit can be released under the project's own licence.

Rebuild everything with `tools/blender/props_build.sh`. It writes the GLB, runs `node tools/props-check.mjs`, renders the contact sheet `tools/shots/props-sheet.png` and the street vignette `tools/shots/props-street.png`.

Conventions:
- One node per model, one mesh per node, one material `toy`.
- Colours are in COLOR_0 (sRGB authored, linear stored).
- The material id is in UV0.u = (id + 0.5) / 16.
- Front is +Z. The origin is on the ground.
- Runtime anchors are stored as node extras (three.js `userData`).
